# Security policy — preview

CloudNest is a local preview. There is no supported production release or
managed public service yet. See docs/security.md for implemented boundaries
and docs/release-readiness.md for release blockers.

Do not put tokens, personal paths, private memories or archive manifests into
public issues. Use GitHub private vulnerability reporting if the repository
owner enables it; no dedicated security contact or response SLA is configured.
If a private channel is unavailable, open an issue containing only a request
for a private reporting channel and no exploit data or personal information.
Do not publish a working credential or private archive to demonstrate a bug.

Maintain independent backups of irreplaceable files. A verified archive is
content integrity evidence, not a guarantee against account loss or provider
retention changes. Stop cleanup if any verification or metadata check fails.
