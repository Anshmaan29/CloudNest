# CloudNest 1.0.0-rc.1 — engineering candidate

Continues Preview 0.5 without replacing its architecture or existing archives.
Public distribution remains blocked; see the [readiness matrix](release-readiness.md).

- Project Hibernation now restores verified Git history, refs, stashes, index and
  working state into a new location, with explicit history-privacy consent,
  dependency instructions and an archive-bound Brain Memory Card. Original
  project cleanup remains disabled when excluded private files prevent coverage.
- Model Parking recognizes current Ollama manifests and LM Studio's llmster
  process. A disposable real Ollama model ran before parking and after verified
  Drive restore. No model runtime is required by CloudNest itself.
- Generated ChatGPT, Claude and bounded Gemini Takeout fixtures exercise
  duplicate detection, provenance, Inbox-only extraction and rollback. Hidden
  ChatGPT analysis/tool text and empty Claude legacy text are handled safely.
- Browser pairing supports a one-time project-scoped connection file and exact
  extension-origin authorization. No owner credential enters the companion.
- Whole-account erasure, explicit audit retention and recovery controls are
  implemented. No live owner account has been irreversibly purged.
- Signed updates now include strict artifact extraction, a native helper,
  atomic app exchange, startup acknowledgment and retained rollback recovery.
  Actual Developer ID/notarized installation remains unverified and disabled.

563 automated checks pass. A fresh installed Codex CLI retrieved the generated
remote memory through MCP using existing ChatGPT authentication; its temporary
read-only grant was revoked afterward. Actual Gemini CLI free authentication
rejected this client with UNSUPPORTED_CLIENT; no paid fallback was used.
The real Docker/PostgreSQL 16 disposable round trip passed 42 checks.

# CloudNest 0.3 — native Storage preview

Continues the verified 0.2 codebase. Adds persistent nested-folder archive and
atomic restore, hidden/empty directory preservation, Archive Library search and
pages, cloud health checks, actual quota reads/preflight and restore-only remote
file catalog recovery. Scan/transfer cancellation, process-level job locks and
shared CLI/native folder protection improve safety. Unknown extended metadata
blocks cleanup; new manifests retain exact bounded OS provenance evidence.

Includes a generated native icon and optional drag-to-Applications DMG, plus a
public-source privacy check in CI. No website, browser console or graph shell
was added. Existing Google and Cloudflare integrations remain separate.

This release is a local ad-hoc preview, not production-ready or notarized.
Folder originals are retained. A portable root manifest is required for folder
reconstruction. See release-readiness.md and verification.md for remaining gates
and the distinction between local tests, live cloud checks and measurements.
